# 🚀 AgriShield AI - Quick Start Guide

## Installation & Setup

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

The app will open at `http://localhost:3000`

---

## 🎯 First Time Setup

### Allow Location Access
When you first open the app, your browser will ask:
```
"AgriShield AI wants to know your location"
```
**Click "Allow"** to get real-time weather data for your area.

> If you click "Block", the app will use default weather data and still work perfectly.

## 🌟 Key Features to Try

### 1. Dashboard - Main Analysis
**Location:** Click "Dashboard" in sidebar

**What to do:**
1. Select your district from dropdown
2. Adjust rainfall forecast slider
3. Adjust temperature slider
4. Click "Generate Intelligence" button
5. See your risk score and crop recommendations

**Look for:**
- Weather widget at top showing current conditions
- Risk score gauge (animated!)
- Top recommended crop card
- Crop ranking table

---

### 2. AI Assistant - Ask Questions
**Location:** Click "AI Assistant" in sidebar

**What to do:**
1. Type a question like:
   - "Which crop is best for low rainfall?"
   - "Why is Bajra recommended?"
   - "What if rainfall drops 20%?"
2. **OR** Click the microphone button and speak your question
3. Get instant AI response

**Voice Input:**
- Click 🎤 microphone button
- Speak clearly in Hinglish, Hindi, or English
- Your speech converts to text automatically
- Press Enter or click Send

**Try these questions:**
```
"Kya grow karu?"
"Kam baarish mein kaunsi fasal best hai?"
"What happens if temperature increases?"
"Tell me about risk score"
```

---

### 3. What-If Engine - Test Scenarios
**Location:** Click "What-If Engine" in sidebar

**What to do:**
1. Move the "Rainfall Variance" slider
   - Left = Drought scenario
   - Right = Flood scenario
2. Move the "Temperature Shift" slider
   - Right = Heatwave scenario
3. Move the "Monsoon Timing" slider
   - Right = Delayed monsoon
4. Watch the risk score change in real-time
5. See how crop rankings change

**Cool feature:** Compare "Before vs After" with animated gauges!

---

### 4. Resilience Analyzer - Compare Crops
**Location:** Click "Resilience" in sidebar

**What to do:**
1. Select different crops from dropdown
2. See their resilience scores:
   - Drought tolerance
   - Heat resistance
   - Rainfall resilience
3. Compare soil compatibility
4. Read AI insights about each crop

---

### 5. District Overview - Regional View
**Location:** Click "Districts" in sidebar

**What to do:**
1. View all monitored districts
2. See risk scores for each district
3. Compare regional climate data
4. Identify high-risk zones

## 🎤 Voice Assistant Tips

### Best Practices
✅ **DO:**
- Speak clearly and at normal pace
- Use simple questions
- Speak in a quiet environment
- Hold microphone button while speaking

❌ **DON'T:**
- Speak too fast
- Use very complex sentences
- Speak in noisy environments

### Supported Languages
- **English:** "Which crop should I grow?"
- **Hindi:** "कौन सी फसल उगाऊं?"
- **Hinglish:** "Kam baarish mein kya grow karu?"

### Troubleshooting
**If voice doesn't work:**
1. Check browser permissions (Settings → Site Settings → Microphone)
2. Try Chrome or Edge (best support)
3. Use text input as fallback

## 🌦️ Weather System

### How It Works
1. **Auto-detect:** App gets your location
2. **Fetch Weather:** Gets real-time data from Open-Meteo
3. **Display:** Shows in weather widget at top of Dashboard
4. **Update:** Refreshes every 30 minutes
5. **Integrate:** Uses weather in risk calculations

### Weather Widget Shows
- 🌡️ Current temperature
- 🌧️ Rainfall amount
- 💧 Humidity percentage
- ☁️ Weather condition

### If Location Blocked
- App uses default weather (28°C, Clear)
- All features still work
- You can manually adjust temperature in Dashboard

## 📊 Understanding Your Results

### Risk Score
- **0-30:** Low Risk (Green) - Safe to proceed
- **30-60:** Moderate Risk (Orange) - Be cautious
- **60-85:** High Risk (Red) - Consider alternatives
- **85-100:** Critical Risk (Dark Red) - High danger

### Crop Rankings
- **Recommended:** Best choice for your conditions
- **Viable:** Good alternative options
- **Shield Index:** Overall suitability score (0-100%)
- **Yield:** Expected harvest in tons per hectare

### AI Insights
Three cards at bottom of Dashboard:
1. **Risk Intelligence:** Overall risk assessment
2. **Optimal Choice:** Why top crop is recommended
3. **Critical Alert:** Important warnings

## 🐛 Troubleshooting

### Weather Not Showing
**Problem:** Weather widget shows "Loading..."
**Solution:**
1. Check internet connection
2. Allow location access
3. Refresh page
4. If still fails, app uses default data

### Voice Not Working
**Problem:** Microphone button doesn't respond
**Solution:**
1. Check browser permissions
2. Use Chrome/Edge browser
3. Check microphone hardware
4. Use text input instead

### Language Not Changing
**Problem:** Text still in wrong language
**Solution:**
1. Click language button again
2. Refresh page
3. Clear browser cache

### Slow Performance
**Problem:** App feels sluggish
**Solution:**
1. Close other browser tabs
2. Clear browser cache
3. Restart browser
4. Check internet speed
